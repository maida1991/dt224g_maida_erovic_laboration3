# Norrgläntan – Laboration 3

Det här projektet är skapat i kursen DT224G – Webbutveckling (Lab3)
Uppgiften var att bygga en responsiv startsida för den fiktiva naturdestinationen Norrgläntan. Jag började med den givna wireframen och skapade sedan en egen mockup i Figma innan jag byggde webbplatsen med HTML och CSS.

## Webbplatsens innehåll

Webbplatsen innehåller ett sidhuvud med navigation, en hero-sektion, en introduktion, tre aktivitetskort, en avslutande sektion och en sidfot med kontaktinformation och länkar.

Aktivitetskorten presenterar:

* Vandra
* Paddla
* Upptäck

## Tekniker

Jag har använt:

* HTML5
* CSS
* Flexbox
* CSS Grid
* media queries
* Git och GitHub
* Figma

## Responsiv design

Webbplatsen är byggd enligt mobile-first-principen. 
På mobil visas navigationen och aktivitetskorten vertikalt. 
På större skärmar visas navigationen horisontellt och aktivitetskorten ligger i tre kolumner.

## Tillgänglighet

Jag har använt semantiska HTML-element, en logisk rubrikstruktur, 
alt-texter för bilder och synliga fokusmarkeringar för tangentbordsnavigering.
